# Little Yiayia Helen's Greek Cookbook

A GitHub Pages-ready website honoring Helen, born in Chicago and raised by Greek immigrant parents.

## About
Helen was born in Chicago and raised by her mother and father who came to Chicago from Greece. This site preserves her family recipes and stories.

## Deploy to GitHub Pages
1. Create a new GitHub repository named `little-yiayia-helens-greek-cookbook`
2. Upload the contents of this folder
3. In repository Settings > Pages, set source to `main` branch `/` root
4. Your site will be live at `https://<username>.github.io/little-yiayia-helens-greek-cookbook/`

## Files
- `index.html` - Home page
- `about.html` - About Yiayia Helen
- `recipes.html` - Family recipes
- `style.css` - Simple styling

Made with love in Chicago.
